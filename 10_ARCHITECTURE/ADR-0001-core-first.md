# ADR-0001 | CORE-first; no chain selected

- **Status:** Proposed, 2026-11-20.
- **Decision:** start modular monolith + transactional ledger + provider simulator; no mint engine or production funds; defer chain selection pending measurable benefit.
- **Alternatives:** token-first / chain-native DEX (reject initially), independent microservices (defer), licensed partner access (preferred future path, not yet contracted).
- **Why:** fewer attack surfaces; clear accountable owner; no regulatory shortcut; test the real user journey first.
- **Revisit when:** competent legal advice identifies applicable permission, verified users need the service, settlement/UX evidence demonstrates blockchain value, reserve/custody/finality obligations are understood.

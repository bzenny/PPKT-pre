# Repo → tested demonstration → prelaunch roadmap

**Gate releases, not estimated calendar promises.** All statuses UNKNOWN until independently supplied evidence exists.

| Gate | Scope | Complete only after |
|---|---|---|
| G0 | Charter and company | competent adoption/authority, money and user rights, non-issued token scope, budget and counsel sign-off |
| G1 | GitHub CORE | branch/security protections, reproducible checks, version/decision registry, maintainer assignments |
| G2 | Google AI Studio | synthetic mobile-first prototype, real task tests and consent/fee clarity |
| G3 | Supabase | permission tests, double-entry and outbox, negative scenarios, backup/restore |
| G4 | Cloudflare | isolated staging, API/auth controls, rate limits, monitoring, incident rehearsals |
| G5 | Chain/provider evaluation | legal scope, partner suitability, security/finality costs; chain testnet only if justified |
| G6 | PPKT VERIFY | independently reviewed evidence, market baseline, adverse cases, security test report |
| G7 | Prelaunch | brand/legal disclosures, authorized service scope, support, demo/production distinction, approved release plan |

**Prelaunch in this charter means a documented, tested, truthful release presentation and authorized *scope*; it does not mean a financial public launch, token distribution or real-money pilot.** A live pilot has additional permissions, insured/segregated funds as applicable, contractual counterparties and monitoring limits.

**First engineering milestone after G0:** one simulated authorized, reconciled and recoverable transaction. **Do not** start with an exchange, DAO, multi-token factory or token sale.

**Added jurisdiction workstream (G0 and G7):** Compare Singapore and exact Dubai zone, select parent company, verify substance, legal/financial partner chain, investor and company rights, Philippine market entry, reserves and tax before accepting funding or enabling live financial operations.

## Cost/risk jurisdiction decisions (G0)
- Keep PH-based development and operations as preferred cost baseline unless validation rejects it.
- Compare Singapore-parent/PH-delivery and Dubai-parent/PH-delivery options on consolidated budgets.
- Verify bank/custodian solvency, segregation, continuity and contract enforceability independently.
- A planning estimate of large savings is not independent confirmation of group-level economics; keep numeric negotiation assumptions private.

# PPKT-pre GitHub workflow

- Repository: `https://github.com/bzenny/PPKT-pre` (public).
- Development target: `foundation/charter-v0.2-core` or a reviewed successor branch.
- Primary `main`: stable pre-release documentation only.
- Recommended: require review, quality CI and a limited set of authorized merge maintainers.
- Do not commit private investor names, terms, banking details, customer data, access tokens or sensitive risk documents.
- Prototype deployment uses synthetic data only and creates no financial issuance or custody authority.
- Official `ppkt-core` release remains a separate gated project decision.

# Product and instrument boundaries

| Label | Immediate stage | Permitted statement | Forbidden claim |
|---|---|---|---|
| PH Probinsyano Token | Brand design | Connected, community-centered service concept | Financial institution / licensed operator |
| PPKT | Project / possible later token symbol | Proposed identifier; no token issued | Peg/redeemability/listing/reserve claims |
| PCCO | No-issued-instrument concept | Pico/Piso participation idea | One-peso unit, guaranteed return, staking right, governance powers today |
| KDef | Proposed funded operating program | Development stewardship plans | Existing independent fund/trust or collateral |

**The 1:1 PHP objective** is deferred to a duly authorized issuer (if ever chosen), qualifying reserve assets and legally enforceable redemption rights. Old token supply, 150% backing and price-control algorithms are **not inherited**. Preserve legacy docs in history only, clearly labeled retired proposals.

**Partner design:** APIs do not confer authorization; name every actor, action, obligation, customer counterparty, outage/reversal and records; require a signed services agreement and legal classification before any real money.

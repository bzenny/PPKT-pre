# Comparative evidence not promotional comparisons

`competitors.json` lists **candidates only**; each field currently says unverified. `benchmarks.json` defines reproducible journeys; the empty `measurements` list is intentional. Compare total user cost, recipient availability, failure rates, unaided comprehension and remedy quality with *the same* amounts, geography, timing and platform conditions. A real observation requires a source or recording, measurement window, reviewer, limitations and freshness. Do not market superiority from an empty table.

The release gate requires at least 3 comparable alternatives including a non-crypto baseline and real measured evidence before final prelaunch. Separate confirmed information from vendor claims; apply versioned research corrections.
